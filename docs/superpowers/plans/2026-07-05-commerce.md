# Commerce Extension Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `glueful/commerce` — headless commerce primitives (catalog, inventory, carts, discounts, checkout, orders, payment seam) as a Glueful extension pack.

**Architecture:** Domain core + contract seams (spec Approach A). Pure `PricingEngine` over integer minor units; oversell-safe conditional stock decrements; one place-order transaction owning stock/discount/order/sequence writes; `TaxCalculator`/`ShippingRateProvider` are commerce-owned contracts with shipped defaults; payments and tenancy compose through `glueful/extension-contracts` — implementations soft-resolve by contract id (`has() ? get() : inline fallback`), never by package class name.

**Tech Stack:** PHP 8.3, Glueful framework (require-dev `^1.65.3`), PHPUnit 10.5 + in-memory SQLite harness (subscriptions pattern), PSR-12 phpcs, PHPStan level 5.

**Spec:** `docs/superpowers/specs/2026-07-05-commerce-design.md`

## Global Constraints

> **AMENDED 2026-07-05 (extension-contracts prerequisite):** commerce consumes
> `glueful/extension-contracts` (spec: `extensions/contracts/docs/superpowers/specs/2026-07-05-extension-contracts-design.md`).
> Three rules override anything below that conflicts:
> 1. **No payvia or tenancy class name appears anywhere in commerce** — not
>    even behind `class_exists`. Composition is contract-only.
> 2. **Soft-binding precedence rule:** commerce NEVER binds a default under a
>    shared contract id (`PaymentCollector::class`, `CurrentTenantResolver::class`,
>    `TenantTableRegistry::class`). Factories resolve
>    `has(Contract::class) ? get(...) : <inline fallback>`.
> 3. **Fail-closed tenant rule:** in tenant mode, a BOUND resolver returning
>    `''` on a scoped path throws (HTTP → 403); sentinel scoping is legal only
>    in non-tenant mode. Only `commerce:tenancy:adopt` and explicitly
>    cross-tenant maintenance CLI bypass, by name.

- Namespace `Glueful\Extensions\Commerce`; PSR-4 `src/`, migrations classmapped at flat `migrations/`.
- `composer.json` requires `glueful/extension-contracts` via a path repository (`{"type": "path", "url": "../contracts"}`) until it is released; pin a real version at release time.
- `tenant_uuid` is `string(12) NOT NULL DEFAULT ''` on EVERY commerce table; every business key is composite-unique with it: `(tenant_uuid, sku)`, `(tenant_uuid, slug)`, `(tenant_uuid, order_number)`, `(tenant_uuid, code)`, `(tenant_uuid, token_hash)`.
- Bearer tokens (cart token, order guest token): CSPRNG raw returned ONCE, only SHA-256 hex stored, header-only presentation (`X-Cart-Token`, `X-Order-Token`), never in query strings, never logged.
- All money is integer minor units; variant currency MUST equal `commerce.currency` (write-time 422 + checkout revalidation).
- Order numbers come from `commerce_sequences` (conditional UPDATE, lazy race-safe INSERT, retry once) — never `max()+1`.
- Discount limits enforce INSIDE the checkout transaction (conditional `usage_count` increment + `buyer_key` composite unique).
- Payment initiation runs AFTER the order transaction commits; failure → order stays `pending_payment` (stock held until expiry), response carries `payment.status = init_failed, retryable: true`.
- Provider `services()` uses `use`-imports (no inline FQCNs); `loadMigrationsFrom()` in `boot()` with `MigrationPriority::DEPENDENT`; cross-extension composition via shared-contract soft-binding (`has() ? get() : inline fallback`) — never `class_exists` on another extension.
- Commit per task in this pack repo (no Claude/Anthropic attribution in commit messages).
- Session conventions: work on `dev`; the final release/tag is the user's.

```php
<?php

declare(strict_types=1);

namespace Glueful\Extensions\Commerce\Support;

/**
 * Integer minor-unit money helpers (spec §7). Arithmetic elsewhere stays pure
 * integer; ONLY display/serialization consults the exponent. The bundled map
 * is the authoritative ISO 4217 validation set: unknown code = invalid.
 */
final class Money
{
    /** Non-2-decimal ISO 4217 exceptions. */
    private const EXPONENT_EXCEPTIONS = [
        'BIF' => 0, 'CLP' => 0, 'DJF' => 0, 'GNF' => 0, 'ISK' => 0, 'JPY' => 0,
        'KMF' => 0, 'KRW' => 0, 'PYG' => 0, 'RWF' => 0, 'UGX' => 0, 'VND' => 0,
        'VUV' => 0, 'XAF' => 0, 'XOF' => 0, 'XPF' => 0,
        'BHD' => 3, 'IQD' => 3, 'JOD' => 3, 'KWD' => 3, 'LYD' => 3, 'OMR' => 3, 'TND' => 3,
    ];

    /** 2-decimal ISO 4217 codes (the common set; extend as needed — data, not logic). */
    private const TWO_DECIMAL = [
        'AED', 'AFN', 'ALL', 'AMD', 'ANG', 'AOA', 'ARS', 'AUD', 'AWG', 'AZN',
        'BAM', 'BBD', 'BDT', 'BGN', 'BMD', 'BND', 'BOB', 'BRL', 'BSD', 'BWP',
        'BYN', 'BZD', 'CAD', 'CDF', 'CHF', 'CNY', 'COP', 'CRC', 'CUP', 'CVE',
        'CZK', 'DKK', 'DOP', 'DZD', 'EGP', 'ERN', 'ETB', 'EUR', 'FJD', 'GBP',
        'GEL', 'GHS', 'GIP', 'GMD', 'GTQ', 'GYD', 'HKD', 'HNL', 'HTG', 'HUF',
        'IDR', 'ILS', 'INR', 'JMD', 'KES', 'KGS', 'KHR', 'KYD', 'KZT', 'LAK',
        'LBP', 'LKR', 'LRD', 'LSL', 'MAD', 'MDL', 'MGA', 'MKD', 'MMK', 'MNT',
        'MOP', 'MUR', 'MVR', 'MWK', 'MXN', 'MYR', 'MZN', 'NAD', 'NGN', 'NIO',
        'NOK', 'NPR', 'NZD', 'PAB', 'PEN', 'PGK', 'PHP', 'PKR', 'PLN', 'QAR',
        'RON', 'RSD', 'RUB', 'SAR', 'SBD', 'SCR', 'SEK', 'SGD', 'SLE', 'SOS',
        'SRD', 'SSP', 'STN', 'SZL', 'THB', 'TJS', 'TMT', 'TOP', 'TRY', 'TTD',
        'TWD', 'TZS', 'UAH', 'USD', 'UYU', 'UZS', 'WST', 'XCD', 'YER', 'ZAR',
        'ZMW',
    ];

    public static function exponentFor(string $code): ?int
    {
        if (isset(self::EXPONENT_EXCEPTIONS[$code])) {
            return self::EXPONENT_EXCEPTIONS[$code];
        }

        return in_array($code, self::TWO_DECIMAL, true) ? 2 : null;
    }

    public static function assertValidCurrency(string $code): void
    {
        if (self::exponentFor($code) === null) {
            throw new \InvalidArgumentException("Unknown ISO 4217 currency code '{$code}'.");
        }
    }

    public static function format(int $amount, string $code): string
    {
        $exp = self::exponentFor($code);
        if ($exp === null) {
            throw new \InvalidArgumentException("Unknown ISO 4217 currency code '{$code}'.");
        }
        if ($exp === 0) {
            return (string) $amount;
        }
        $sign = $amount < 0 ? '-' : '';
        $abs = abs($amount);
        $div = 10 ** $exp;

        return sprintf('%s%d.%0' . $exp . 'd', $sign, intdiv($abs, $div), $abs % $div);
    }
}
```

`src/Support/TokenHasher.php`:

```php
<?php

declare(strict_types=1);

namespace Glueful\Extensions\Commerce\Support;

/**
 * Bearer-token hygiene (spec §2): CSPRNG raw returned once, SHA-256 hex is the
 * ONLY stored form, lookups compare by hash. Header-only presentation is the
 * HTTP layer's job; this class never logs.
 */
final class TokenHasher
{
    /** @return array{raw: string, hash: string} */
    public static function generate(): array
    {
        $raw = bin2hex(random_bytes(20));

        return ['raw' => $raw, 'hash' => hash('sha256', $raw)];
    }

    public static function hash(string $raw): string
    {
        return hash('sha256', $raw);
    }
}
```

```php
namespace Glueful\Extensions\Commerce\Tests\Support;

use Glueful\Bootstrap\ApplicationContext;
use Glueful\Database\Connection;
use PHPUnit\Framework\TestCase;
use Psr\Container\ContainerInterface;

abstract class CommerceTestCase extends TestCase

    protected ApplicationContext $context;
    protected Connection $connection;

    /** @var array<string,mixed> extra container bindings a test may inject */
    protected array $bindings = [];

    /** Migration classes to run — appended in Task 2. */
    protected const MIGRATIONS = [];

    protected function setUp(): void
    {
        parent::setUp();

        $this->connection = new Connection([
            'engine' => 'sqlite',
            'sqlite' => ['primary' => ':memory:'],
            'pooling' => ['enabled' => false],
        ]);

        $schema = $this->connection->getSchemaBuilder();
        foreach (static::MIGRATIONS as $migration) {
            (new $migration())->up($schema);
        }

        $connection = $this->connection;
        $bindings = &$this->bindings;

        $container = new class ($connection, $bindings) implements ContainerInterface {
            /** @param array<string,mixed> $bindings */
            public function __construct(
                private Connection $connection,
                private array &$bindings,
            ) {
            }

            public function get(string $id): mixed
            {
                if ($id === 'database' || $id === Connection::class) {
                    return $this->connection;
                }
                if (array_key_exists($id, $this->bindings)) {
                    return $this->bindings[$id];
                }
                throw new \RuntimeException("Unknown service: {$id}");
            }

            public function has(string $id): bool
            {
                return $id === 'database'
                    || $id === Connection::class
                    || array_key_exists($id, $this->bindings);
            }
        };

        $this->context = new ApplicationContext(basePath: sys_get_temp_dir(), environment: 'testing');
        $this->context->setContainer($container);
        $this->context->mergeConfigDefaults('commerce', require __DIR__ . '/../../config/commerce.php');
    }

    protected function appContext(): ApplicationContext
    {
        return $this->context;
    }
}
```

```php
public function createProduct(ApplicationContext $context, array $input): array
{
    $tenant = $this->tenants->tenantUuid($context);
    $storeCurrency = (string) config($context, 'commerce.currency', 'USD');
    Money::assertValidCurrency($storeCurrency);

    $variants = $input['variants'] ?? [];
    if ($variants === []) {
        throw ValidationException::forField('variants', 'A product needs at least one variant.');
    }
    foreach ($variants as $i => $v) {
        if (($v['currency'] ?? $storeCurrency) !== $storeCurrency) {
            throw ValidationException::forField(
                "variants.{$i}.currency",
                "Variant currency must equal the store currency ({$storeCurrency})."
            );
        }
        if (!is_int($v['price'] ?? null) || $v['price'] < 0) {
            throw ValidationException::forField("variants.{$i}.price", 'Price must be a non-negative integer (minor units).');
        }
    }
    // Pre-checks for slug/sku (friendly 422); composite uniques are the backstop.
    if ($this->products->findBySlug($context, $tenant, (string) $input['slug']) !== null) {
        throw ValidationException::forField('slug', 'Slug already in use.');
    }
    foreach ($variants as $i => $v) {
        if ($this->variants->findBySku($context, $tenant, (string) $v['sku']) !== null) {
            throw ValidationException::forField("variants.{$i}.sku", 'SKU already in use.');
        }
    }

    $productUuid = Utils::generateNanoID();
    $type = (string) ($input['type'] ?? 'physical');
    $this->products->insert($context, [
        'uuid' => $productUuid, 'tenant_uuid' => $tenant,
        'slug' => (string) $input['slug'], 'name' => (string) $input['name'],
        'description' => $input['description'] ?? null, 'type' => $type,
        'status' => (string) ($input['status'] ?? 'draft'),
        'options' => $input['options'] ?? null, 'metadata' => $input['metadata'] ?? null,
    ]);

    $created = [];
    foreach ($variants as $pos => $v) {
        $variantUuid = Utils::generateNanoID();
        $this->variants->insert($context, [
            'uuid' => $variantUuid, 'tenant_uuid' => $tenant, 'product_uuid' => $productUuid,
            'sku' => (string) $v['sku'], 'option_values' => $v['option_values'] ?? [],
            'price' => (int) $v['price'], 'compare_at_price' => $v['compare_at_price'] ?? null,
            'currency' => $storeCurrency, 'position' => $pos, 'status' => 'active',
        ]);
        // Stock row: physical = tracked (qty 0), digital = untracked.
        db($context)->table('commerce_stock')->insert([
            'uuid' => Utils::generateNanoID(), 'tenant_uuid' => $tenant,
            'variant_uuid' => $variantUuid, 'quantity' => 0, 'tracked' => $type === 'physical' ? 1 : 0,
        ]);
        $created[] = $this->variants->findByUuid($context, $tenant, $variantUuid);
    }

    $product = $this->products->findByUuid($context, $tenant, $productUuid);
    $product['variants'] = $created;

    return $product;
}
```

```php
    $subtotal = 0;
    foreach ($lines as $l) {
        $subtotal += $l['unit_price'] * $l['quantity'];
    }

    $shippingTotal = $shipping?->amount ?? 0;
    $discountTotal = 0;

    if ($discount !== null) {
        $base = $this->discountableBase($lines, $discount['product_scope'] ?? null);
        $discountTotal = match ((string) $discount['type']) {
            'percentage' => intdiv($base * (int) $discount['value'] + 5000, 10000), // bps, half-up
            'fixed' => min((int) $discount['value'], $base),
            'free_shipping' => $shippingTotal,
            default => 0,
        };
        if (($discount['type'] ?? '') === 'free_shipping') {
            $shippingTotal = 0;
        }
        $discountTotal = min($discountTotal, $subtotal + ($shipping?->amount ?? 0)); // global clamp
    }

    $taxTotal = $tax?->amount ?? 0;
    $grand = max(0, $subtotal - ($discount !== null && $discount['type'] !== 'free_shipping' ? $discountTotal : 0))
        + $shippingTotal + $taxTotal;

    return new Totals($subtotal, $discountTotal, $shippingTotal, $taxTotal, $grand);
}
```

```php
public function placeOrder(ApplicationContext $context, string $rawCartToken, array $buyer, array $addresses, ?string $shippingMethodId): array
{
    $cart = $this->carts->byToken($context, $rawCartToken);
    if ($cart === null) {
        throw ValidationException::forField('cart', 'Cart not found or no longer active.');
    }
    $tenant = $this->tenants->tenantUuid($context);
    $lines = $this->carts->pricedLines($context, $cart);
    if ($lines === []) {
        throw ValidationException::forField('cart', 'Cart is empty.');
    }

    $storeCurrency = (string) config($context, 'commerce.currency', 'USD');
    foreach ($lines as $i => $l) {
        if (($l['currency'] ?? $storeCurrency) !== $storeCurrency) {
            throw ValidationException::forField("lines.{$i}", 'Variant currency no longer matches the store currency.');
        }
    }

    $discount = null;
    if (($cart['discount_code'] ?? null) !== null) {
        $discount = $this->discounts->findByCode($context, $tenant, $cart['discount_code']);
        if ($discount !== null) {
            $subtotal = array_sum(array_map(fn($l) => $l['unit_price'] * $l['quantity'], $lines));
            $this->discountService->validateForCart($context, $discount, $subtotal, $lines);
        }
    }

    $shippingQuote = $this->resolveShipping($context, $lines, $addresses['shipping'] ?? [], $shippingMethodId);
    $preTax = /* subtotal - discount + shipping, from PricingEngine partials */
        $this->pricing->price($lines, $discount, $shippingQuote, null);
    $taxQuote = $this->tax->quote($context, $preTax->grandTotal, $addresses['shipping'] ?? []);
    $totals = $this->pricing->price($lines, $discount, $shippingQuote, $taxQuote);

    $buyerIdentity = $buyer['user_uuid'] ?? strtolower((string) $buyer['email']);
    $guestToken = TokenHasher::generate();

    $order = db($context)->transaction(function () use ($context, $tenant, $cart, $lines, $discount, $shippingQuote, $totals, $buyer, $buyerIdentity, $guestToken, $addresses) {
        // 1) Oversell gate (spec §4): tracked lines decrement conditionally.
        foreach ($lines as $l) {
            if (!$this->stock->isTracked($context, $tenant, $l['variant_uuid'])) {
                continue;
            }
            if (!$this->stock->decrement($context, $tenant, $l['variant_uuid'], $l['quantity'])) {
                throw new InsufficientStockException($l['variant_uuid'], $l['sku']);
            }
        }

        // 2) Order number under the sequence row lock.
        $orderUuid = Utils::generateNanoID();
        $number = $this->numbers->next($context, $tenant);

        foreach ($lines as $l) {
            if ($this->stock->isTracked($context, $tenant, $l['variant_uuid'])) {
                $this->stock->recordMovement($context, $tenant, $l['variant_uuid'], -$l['quantity'], 'order', $orderUuid);
            }
        }

        // 3) Transactional discount consumption (spec §4 P1).
        if ($discount !== null) {
            $this->discountService->consume($context, $discount, $orderUuid, $buyerIdentity);
        }

        // 4) Order + snapshot lines + audit event.
        $this->orders->insert($context, [
            'uuid' => $orderUuid, 'tenant_uuid' => $tenant, 'order_number' => $number,
            'status' => 'pending_payment', 'email' => (string) $buyer['email'],
            'user_uuid' => $buyer['user_uuid'] ?? null, 'guest_token_hash' => $guestToken['hash'],
            'currency' => (string) config($context, 'commerce.currency', 'USD'),
            'subtotal' => $totals->subtotal, 'discount_total' => $totals->discountTotal,
            'shipping_total' => $totals->shippingTotal, 'tax_total' => $totals->taxTotal,
            'grand_total' => $totals->grandTotal,
            'discount_code' => $discount['code'] ?? null,
            'shipping_method' => $shippingQuote?->id,
            'addresses' => $addresses, 'placed_at' => gmdate('Y-m-d H:i:s'),
        ], $lines);
        $this->orders->recordEvent($context, $orderUuid, 'placed', ['number' => $number]);

        // 5) Cart converts inside the same transaction.
        db($context)->table('commerce_carts')->where('uuid', '=', $cart['uuid'])->update(['status' => 'converted']);

        return $this->orders->findByUuid($context, $tenant, $orderUuid);
    });

    $this->dispatch($context, new OrderPlaced($order));

    // Payment initiation AFTER commit — explicit failure semantics (spec §4 P1).
    // AMENDED: the collector is the SHARED contract; the order travels as a
    // PayableReference. $this->collector is injected by the provider factory:
    // has(PaymentCollector::class) ? get(...) : new ManualPaymentCollector().
    $payable = new PayableReference(
        'commerce_order',
        $order['uuid'],
        (int) $order['grand_total'],
        (string) $order['currency'],
        'Order ' . $order['order_number'],
    );
    try {
        $init = $this->collector->initiate($context, $payable);
        $this->orders->recordEvent($context, $order['uuid'], 'payment_initiated', ['provider' => $init->provider]);
        $payment = ['status' => $init->status, 'provider' => $init->provider, 'payload' => $init->payload];
    } catch (\Throwable $e) {
        $this->orders->recordEvent($context, $order['uuid'], 'payment_init_failed', ['error' => $e->getMessage()]);
        $payment = ['status' => 'init_failed', 'retryable' => true];
    }

    return ['order' => $order, 'guest_token' => $guestToken['raw'], 'payment' => $payment];
}
```
